# Project scripts

- `update-download-links.mjs`: Updates README download links from `VERSION`.
- [metadata/](metadata/README.md): Generates platform metadata from shared resources.
- `aur/`: Prepares the AUR recipe from published Arch packages.
- `flatpak/`: Generates dependency sources and prepares Flatpak manifests.
- `licenses/`: Collects backend licenses and combines frontend/backend reports with application
  and platform notices into `.generated/licenses/THIRD-PARTY-NOTICES.json`.

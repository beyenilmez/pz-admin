# Security Policy

## Supported versions

Only the latest release line receives security updates. Older versions are not
supported.

| Version            | Supported          |
| ------------------ | ------------------ |
| Latest 2.x release | :white_check_mark: |
| Older 2.x releases | :x:                |
| 1.x                | :x:                |

## Reporting a vulnerability

**Do not report vulnerabilities in public issues or pull requests.**

1. **Report privately**

   Use [GitHub Security Advisories](https://github.com/beyenilmez/pz-admin/security/advisories/new).
   If private reporting is unavailable, email
   [contact@bedirhanyenilmez.com](mailto:contact@bedirhanyenilmez.com).

2. **Include in your report**

   - A description of the vulnerability and its impact.
   - Reproduction steps or a minimal proof of concept.
   - App version, OS, and installation format.
   - Server build and relevant configuration, if applicable.

   Remove passwords, tokens, and other private information from examples and logs.

3. **What to expect**

   - Your report will be acknowledged and you can expect a response within a reasonable time.
   - More details may be requested.
   - Once the issue is fixed, disclosure can be coordinated and you may be credited if you wish.

Please allow time to investigate and address the issue before publishing details.
Test only against systems you own or have permission to assess.

## Scope

Report vulnerabilities affecting PZ Admin, including its use of dependencies.
Vulnerabilities solely in Project Zomboid or unrelated third-party systems are
outside this policy's scope. If you're unsure, submit a private report.

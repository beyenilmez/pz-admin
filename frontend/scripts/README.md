# Frontend scripts

- `catalogs/`: Generate item and vehicle catalogs and extract server-option reference data from game files and the wiki.
- `translations/`: Import game translations, format translation files, and validate UI translation keys.
- `icons/`: Generate PNG icons and Icon Composer assets from the application SVG.
- `licenses/`: Combine Vite's dependency license report with additional notices.
- `screenshots/`: Export application screenshots.
- `shared/`: Shared helpers.

See [`../package.json`](../package.json) for script commands.

These scripts are mostly AI-generated. The review covered reading each script and understanding its purpose and behavior, rather than checking every implementation detail.

# Catalog sources and changes

These catalogs use material by PZwiki contributors under
[CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/).
Game-owned material is covered separately, as described below and in the
[PZwiki copyright policy](https://pzwiki.net/wiki/PZwiki:Copyrights).

Sources:

- [PZwiki:Item list](https://pzwiki.net/wiki/PZwiki:Item_list); the Build 41
  generator defaults to [revision 512551](https://pzwiki.net/w/index.php?oldid=512551).
- [Skills](https://pzwiki.net/wiki/Skills), including skill categories and XP tables.
- [Vehicle](https://pzwiki.net/wiki/Vehicle), including the individual vehicle and variant pages linked there.

For PZ Admin, the wiki material was converted to JSON, organized into catalogs,
and updated with normalized names and values, local image paths, and corrections.
These adaptations retain CC BY-NC-SA 3.0. Source revisions are not available for
every entry.

The item catalogs also use names and categories extracted from the game.
Vehicle catalogs and `stats.json` files combine wiki data, game-extracted values,
and in-game observations. Extracted translations and other game-owned content
remain subject to [The Indie Stone's terms](https://projectzomboid.com/blog/support/terms-conditions/).
